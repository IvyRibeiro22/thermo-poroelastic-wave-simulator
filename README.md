
# Thermo-Poroelastic Wave Simulator

Simulador numérico desenvolvido em Python para o estudo da
dispersão e atenuação de ondas em meios termo-poroelásticos
unidimensionais.

## Objetivo

Investigar a influência das propriedades mecânicas, hidráulicas
e térmicas na propagação de ondas em meios porosos saturados.

## Modelagem física

O projeto utiliza uma formulação termo-poroelástica recíproca,
considerando dois modelos de resistência ao escoamento:

- Modelo de Darcy
- Modelo de Biot-JKD

Serão investigados três modos de propagação:

- P1: onda compressional rápida
- P2: onda compressional lenta
- T: modo térmico
